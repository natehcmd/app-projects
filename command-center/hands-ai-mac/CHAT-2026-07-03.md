## What Hands AI is

Native SwiftUI macOS app that lives as a floating frosted-glass panel. Talks
directly to a local Ollama server (no Python daemon in the middle). Has real
tools it can call, speaks replies out loud, shows a live system-stats
dashboard. Single-instance, hotkey-summonable, status-bar icon uses your
pixel-art logo.

### Architecture

```
SwiftUI panel  ⇄  OllamaClient  ⇄  http://127.0.0.1:11434 (ollama)
                       │
                       └── Tools.swift executes calls in-process:
                           read_file, write_file, list_dir, run_bash, get_stats
```

### Shipped feature list

- **Floating frosted-glass panel** (`NSPanel` + `NSVisualEffectView`, Option+Space global hotkey, status-bar icon)
- **Single-instance enforcement** via `NSRunningApplication` check at launch
- **Animated Jarvis-style orb** (SwiftUI `TimelineView` + `Canvas`) with 10 states: idle, listening, thinking, reading, writing, editing, bash, web, speaking, error
- **Real tool calling** with native `tool_calls` support + content-embedded fallback parser (`OllamaClient.rescueContentToolCalls`) for models that stuff JSON into the content field
- **5 tools**: `read_file`, `list_dir`, `write_file`, `run_bash`, `get_stats`
- **Live system stats page**: CPU %, per-core grid, RAM, disk, network, thermal state, battery, top processes — pulled via mach `host_statistics64` + `sysctl` + `pmset`
- **Voice input**: `SFSpeechRecognizer` + `AVAudioEngine`
- **Voice output**: `AVSpeechSynthesizer` with best-quality voice picker, speech sanitization (strips markdown/code/JSON before speaking), 1–3 sentence trimmer
- **Chat with Bubbles/Plain toggle** — Plain mode uses `NSTextView` for true drag-select across the whole conversation + ⌘C
- **Copy conversation** button + per-bubble context menu (Copy / Speak again)
- **Ollama offline banner** with Retry button
- **Voice quality banner** when only Default-quality voices installed, with one-click jump to System Settings for Premium Daniel download
- **Traffic-light close/hide buttons** in the title bar
- **App icon**: user's pixel-art logo at 7 sizes; in-app brand mark uses same PNG with `interpolation: .none` for crisp pixel rendering

## Big decisions locked in

1. **Direct Ollama, no Python daemon.** Previous prototype had a Python + Electron stack; both retired. Everything is Swift + Ollama now.
2. **`devstral:latest` is the default model.** The only model in the user's installed set that emits native `tool_calls` reliably AND has no fine-tuned persona baked in. Preference chain: `devstral → qwen3.6 → qwen2.5-coder → hermes → llama3.1 → llama3.2`.
3. **Banned model prefixes** — `["custom-", "private-"]` are auto-ejected from the picker on every refresh, to prevent user-owned fine-tunes from leaking their trained persona regardless of system prompt.
4. **Identity lock** in the system prompt: hard clause telling the model to ignore any name from its training weights + explicit voice-length rule (1–3 sentences).
5. **macOS runtime clause** in the system prompt so models don't emit Linux-style `/home/...` paths.
6. **Content-embedded tool-call rescue** — if a model returns tool JSON inside the `content` field instead of `tool_calls`, `OllamaClient.rescueContentToolCalls` parses it and rewrites the message before the agent loop sees it. Makes the app work with weaker models.
7. **`OS_ACTIVITY_MODE=disable`** at startup to silence macOS framework log spam (linkd, `nw_*`, Process Instance Registry chatter).
