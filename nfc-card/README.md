# nfc-card

A custom NFC digital business card — tap-to-open mobile contact page built for Nate Howard at JOV AI.

## What it does

Tap an NFC-enabled card or open the link on mobile, and you get a polished contact page with name, title, photo, and links. No app required.

## Stack

- Pure HTML/CSS — zero dependencies, instant load
- Mobile-first layout, dark theme
- Hosted via GitHub Pages

## Live

Linked to a physical NFC card for real-world use.
